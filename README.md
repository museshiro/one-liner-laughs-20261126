## The joke

> My keyboard's spacebar only sticks on the word 'sorry' — even my hardware is tired of my apologies.

## How it works

`main.ts` (Node 22) writes exactly one line — the joke above — to `/output/entry.txt` and nothing else. It refuses to write if the line is empty or over 200 characters.

## Verification
